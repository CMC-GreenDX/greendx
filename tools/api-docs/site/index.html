EcoTrace API

Every feature of the EcoTrace console is available to other applications through these APIs: upload and read documents, turn them into Scope 1 and 2 emissions, approve them, seal a period and export the inventory.

API guide Postman collection Source code
This page documents the API; it is not connected to a server, so Try it out is turned off. To call the API, run EcoTrace (make up) and open /api-docs on it, or use the Postman collection. Every call needs a Keycloak access token: see Authentication in the API guide.
