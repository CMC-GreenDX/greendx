# apps

Tier 3 business apps. Each app is a plug-in that subscribes to domain events and can be enabled or disabled per tenant in `tenant.yaml`.

| Folder | Purpose |
|---|---|
| `carbon-ledger/` | Scope 1 and 2 emissions with lineage to source documents and a tamper-evident seal |
| `purchase-approval/` | Minimal second consumer that proves the core and intake are reusable |
